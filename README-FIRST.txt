LIVE TRANSLATE - QUICK START (Windows)
======================================

1) Install Node.js (one time only)
   Go to https://nodejs.org , download the "LTS" version, install with the default options.

2) Unzip this folder somewhere easy, for example  C:\LiveTranslate
   (Right-click the zip > Extract All. Do not run it from inside the zip.)

3) Double-click  start.bat
   - A black window opens (keep it open while you use the app).
   - Your browser opens the control panel.
   - If Windows Firewall asks, click "Allow access" (Private networks). Phones need this.

4) Try it without any keys
   On the Live tab choose Engine = "Demo" and press "Start listening".
   Then press "Open big screen" on the left.

5) For a real event, open the Settings tab and paste two keys:
   - Deepgram key  (speech to text)   https://deepgram.com
   - Anthropic key (translation)      https://console.anthropic.com
   Then choose Engine = "Deepgram" and press Start listening.

6) Audience phones
   Same Wi-Fi as the laptop (or the laptop's hotspot). Tick "Show the QR code on the big screen"
   or share the link shown in "Invite the audience". They scan, pick up to 4 languages, and read.

To stop the app: close the black window.
Your settings, pictures and transcripts are saved in the "data" folder next to start.bat.
